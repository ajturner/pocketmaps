One sheet · eight pages · no app

Your data, folded into a pocket map.

Point PocketMaps at a feature layer, a filtered ArcGIS Hub dataset, or any GeoJSON. It lays out a title page, a map for every place, and a numbered index on one printable sheet that folds into a tiny booklet.

How it works

1

Point at data

Paste a FeatureServer layer with a where clause, a Hub dataset page, or a GeoJSON URL or file. Or click the bookmarklet on any Hub site.

2

Generate

Pick the name and description fields. Each place gets a street map, with an optional city and region overview, and the index maps every stop by page number.

3

Print and fold

Print at 100% on one side. Six folds and one cut turn the sheet into a booklet. The index has a QR code to a live map, where anyone can print their own copy.

Examples to try

Each one opens the generator with real public data and builds the booklet in a few seconds.

Browsing ArcGIS Hub?

Add the PocketMap bookmarklet from the generator’s “Use from ArcGIS Hub” panel. On any dataset page, filtered or not, one click opens the same data here as a booklet.
